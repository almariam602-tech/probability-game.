# 🎯 مغامرة هرم بلوم في عالم الاحتمال

لعبة تعليمية تفاعلية لدرس **الاحتمال** — الرياضيات، الصف الرابع الابتدائي.
إعداد المعلمة: مريم علي.

## ما الذي تحتويه اللعبة؟
- هرم بلوم بست طبقات: التذكر، الفهم، التطبيق، التحليل، التقييم، الإبداع (٣ أسئلة لكل مستوى).
- ثلاثة مسارات: **المستكشفة** (أرقام صغيرة وتلميح متاح من البداية)، **المحللة** (ألوان أكثر وخيارات أوسع)، **المبدعة** (أعداد أكبر وتبرير مكتوب في التصميم).
- أكياس كرات وعجلة حظ ومكعب أعداد، مع زر «اسحبي كرة» للتجريب (النتيجة عشوائية وتُذكَّر الطالبة بأنها لا تغيّر الاحتمال).
- نقاط (١٠ / ٦ / ٣ بحسب عدد المحاولات)، نجوم، شارات، شريط تقدم، شهادة إنجاز قابلة للطباعة.
- لوحة المعلمة: صحيح وخطأ، الدرجة ونسبة الإتقان، أداء كل مستوى، توصية علاجية أو إثرائية، طباعة التقرير، تصدير CSV.

> ⚠️ النتائج تُحفظ في `localStorage` على جهاز الطالبة فقط، ولا تُرسل تلقائيًا للمعلمة ولا تُحفظ في حساب سحابي.
> لذلك تطلب المعلمة من الطالبة طباعة التقرير أو تصدير CSV. ولوحة المعلمة تعرض نتائج الجهاز الذي تُفتح عليه.

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | هيكل الصفحة |
| `style.css` | التصميم (RTL، طباعة، جوال) |
| `script.js` | منطق اللعبة، وبنك الأسئلة في الأعلى (`BANK` و`BUILD`) |

## تعديل الأسئلة
افتحي `script.js` وابحثي عن `BANK`. الصحيح دائمًا **أول خيار** (ويُخلط عند العرض). الأرقام تتغير بحسب المسار عبر `n([مستكشفة, محللة, مبدعة])`.
تُحسب أوصاف الاحتمال تلقائيًا بالدالة `cls`، فلا تكتبي الإجابة يدويًا إذا كان السؤال مبنيًا على كيس.

## الرفع إلى GitHub (من المتصفح)
1. ادخلي إلى github.com وسجّلي الدخول (أو أنشئي حسابًا مجانيًا).
2. اضغطي **+** أعلى الصفحة ثم **New repository**.
3. اكتبي اسمًا بالإنجليزية مثل `probability-game`، واختاري **Public**، ثم **Create repository**.
4. اضغطي **uploading an existing file**.
5. اسحبي الملفات الأربعة (`index.html` و`style.css` و`script.js` و`README.md`) إلى الصفحة، وتأكدي أنها في الجذر لا داخل مجلد.
6. اضغطي **Commit changes**.

## تفعيل GitHub Pages
1. من المستودع افتحي **Settings**.
2. من القائمة الجانبية اختاري **Pages**.
3. تحت **Build and deployment** اجعلي Source: **Deploy from a branch**.
4. اختاري Branch: **main** والمجلد **/ (root)** ثم **Save**.
5. انتظري دقيقة أو دقيقتين وحدّثي الصفحة؛ يظهر الرابط بالشكل:
   `https://اسم-المستخدم.github.io/probability-game/`

## التضمين في Google Sites
1. افتحي موقعك في Google Sites واختاري الصفحة.
2. من **إدراج (Insert)** اختاري **تضمين (Embed)**.
3. في تبويب **By URL** الصقي رابط GitHub Pages، ثم **Insert**.
4. كبّري الإطار ليملأ الصفحة، ثم اضغطي **Publish**.

إن لم يظهر الإطار جيدًا، استخدمي تبويب **Embed code** والصقي:
```html
<iframe src="رابط-اللعبة" width="100%" height="900" style="border:0" allowfullscreen></iframe>
```
**ملاحظة:** قد تحتاج طباعة الشهادة إلى فتح اللعبة في تبويب مستقل بدل الإطار المضمَّن.
